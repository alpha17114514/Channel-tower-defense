## 后续版本归档方式

1. 将新版本完整 HTML 文件放入本目录，文件名采用 `通道塔防v版本号.html`，例如 `通道塔防v10.5.html`。
2. 保留所有已发布的旧版本文件，不要用新版本替换它们。
3. 发布新版本后，在上方表格增加一行，填写版本号、文件链接和简短更新说明。
4. 如果 `index.html` 是 GitHub Pages 的游玩入口，更新它时也应同时把对应版本副本存入本目录。

Git 的提交历史也会保留文件的历次修改；本目录则用于方便玩家直接找到并下载各个版本。
